# Carpet RuneLegend Addition

[中文](README.md) | **English**

An **independent** Carpet extension mod for the RuneLegend game mode. 

It mainly adjusts vanilla Minecraft mechanics through the Carpet rule system, aiming to make vanilla Minecraft behavior as close as possible to EaseCation's official RuneLegend, and to give map developers convenient rule configuration.
